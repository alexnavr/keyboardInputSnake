### Сборка
```
make
```

### Файл смежности
Находится в `data/qwerty.txt`

Формат: `a zsq` где a - клавиша, zsq - смежные клавиши, для каждой клавиши своя строка

Если не устраивает заданная смежность, смело ее редактируйте!

### Формат словаря
`data/correct.txt` содержит корректные сочетания

`data/uncorrect.txt` содержит некорректные сочетания

`data/dictionary.txt` содержит комбинацию корректных и некорректных сочетаний

Одно слово на строку

Длина слова не должна превышать 255 символов (можно изменить в коде)

Строки с небуквенными символами или пустые строки игнорируются


### Запуск
Использование заданного словаря (`data/dictionary.txt`)
```
./out/program 
```

Использовать кастомный словать
```
./out/program [словарь.txt]
```
